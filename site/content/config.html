Configuration reference

Every setting of /etc/kbf/kbf.toml, by table. A key is the long name of a flag (--storage-listen is storage-listen), and a flag on the command line overrides the key. A secret is never a value: the key holds the path of the file that has it. The file must not be writable by group or other. The modes are frontend, storage, daemon, storage-and-daemon, all-in-one.

The source of truth is the templates in crates/kbf-cli/tests/golden, which a test holds equal to the flag definitions in kbf-cli. Where this page and a template differ, the template is right.
