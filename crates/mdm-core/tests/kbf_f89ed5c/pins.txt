# The upstream binaries `kbf-deploy mdm fetch` downloads and `mdm install` installs:
# tool, version, URL, sha256 of the download. Compiled into kbf-deploy; both verbs
# refuse an archive whose sha256 differs. Each pin equals the sha256 GitHub records for
# the release asset (`gh api repos/OWNER/REPO/releases/tags/TAG --jq '.assets[] |
# .name, .digest'`), except scepserver, whose release predates asset digests: its pin
# is the hash of a first download, so it proves "the same bytes as then", not
# provenance. None of NanoHUB, NanoDEP, the SCEP server or MicroMDM publishes a
# signature; lego and Caddy publish checksum files (the pins agree with them).
# To move a pin: change version, URL and hash together, in one commit, with the
# release notes read; the parser refuses a URL without /v<version>/.
